# 在官网后台新增案例

1. 打开 [官网后台](https://empact.cn/admin/)，登录后进入「新增项目」。
2. 点击「新增项目」，填写名称、简短介绍并选择所属业务类型，再点「创建并编辑」。案例会显示在所选业务页面下。
3. 在「通用与媒体」的「图片」字段选择封面，可从媒体库选图或上传。支持 JPG、PNG、WebP，单张不超过 5 MB；填写「替代文字」，用一句话说明图片内容。优先用有公开使用许可、与该案例对应的活动照片。
4. 选择详情展示方式：已有公众号文章时填写「详情外链」；需要官网文章时留空外链，在「正文」中填写内容、插入图片。填写外链后，读者会直接跳转到该链接。
5. 保存草稿，再点「预览草稿」。检查标题、摘要、封面、所属业务及正文；外链案例打开详情链接核对。站内草稿预览需要登录，有效期一小时。
6. 确认内容后点「发布到官网」，在弹窗中确认，等待上线结果。所属业务须先发布；发布失败时，原官网版本继续保留。
7. 打开官网对应业务页面，检查新卡片及详情。保存草稿本身不会更新官网。

后续修改已上线案例：进入「管理已发布项目」，编辑并保存后点「发布更新」。暂未上线的内容在「管理草稿」中继续编辑。若暂时不展示，可用「撤下」保留内容；「删除」会撤下并删除记录。
