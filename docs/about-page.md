# 关于 Empact 页面

`/about/` 按提供的 `关于Empact页面_demo.html` 实现，复用站点导航和页脚。文案采用同目录内容梳理方案 v2 的口径；咨询区只显示合作入口，联系方式统一显示在站点页脚。

## 内容来源

- `packages/content/src/about.ts` 保存 demo 的语义 HTML 和摘要，供预览 fixture 使用。
- 页面实际读取当前快照中 `about` 条目的 `bodyHtml`；不会以默认内容覆盖已编辑或发布的正文。
- 此次代码更新不改写现有 CMS 数据库，也不执行发布。现有 CMS 条目需在编辑器中录入对应模板正文并经过原有审核、发布流程后，才会采用新布局。

## 编辑约定

模板依次使用九个二级标题：首屏、概况数据、我们是谁、中国业务、影响力、历程、荣誉、团队、咨询。首屏标题在页面显示为唯一的一级标题。

统计、服务、指标、历程、荣誉和团队使用三级标题分组。保留分组结构时，可修改文字、数字及链接；也可按同类结构增减卡片。提示语使用引用块。咨询区展示介绍段落和链接列表；为兼容已有内容快照，模板中的邮箱和地址段落仍可读取，但不在咨询区重复展示。

解析器遇到旧正文或不符合模板的结构时，完整显示普通正文，不丢弃内容。更改区块顺序、增加介绍段落等操作可能触发普通正文布局；大幅调整内容结构时，应同步调整解析器和测试。

## 验证

`tests/about-parser.test.ts` 覆盖 CMS 文案变更、HTML 清理和普通正文回退。`tests/browser/about.spec.ts` 覆盖页面层级、卡片分组、移动端溢出、数据分隔线、重复联系方式隐藏和实际路由跳转。
