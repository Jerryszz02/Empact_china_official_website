# 关于 Empact 页面

`/about/` 按提供的 `关于Empact页面_demo.html` 实现，复用站点导航和页脚。文案采用同目录内容梳理方案 v2 的口径；咨询区只显示合作入口，联系方式统一显示在站点页脚。

## 内容来源

- `packages/content/src/about.ts` 保存 demo 的语义 HTML 和摘要，供预览 fixture 使用。
- 页面实际读取当前快照中 `about` 条目的 `bodyHtml`；不会以默认内容覆盖已编辑或发布的正文。
- 代码部署不会改写现有 CMS 数据库。现有正文可使用下述定向更新命令准备草稿，再经过原有审核、发布流程生效。

## 影响地点口径

2026-09-22 经业务方重新核对，亚太影响地点数量统一为 12；首屏说明、概况数据和影响力指标使用同一数字。旧公司介绍资料中的 13 保留为历史来源，不作为当前页面口径。CMS 已有正文须同步修改，代码模板更新不会自动覆盖已发布内容。

## 编辑约定

模板依次使用九个二级标题：首屏、概况数据、我们是谁、中国业务、影响力、历程、荣誉、团队、咨询。首屏标题在页面显示为唯一的一级标题。

统计、服务、指标、历程、荣誉和团队使用三级标题分组。保留分组结构时，可修改文字、数字及链接；也可按同类结构增减卡片。提示语使用引用块。咨询区展示介绍段落和链接列表；为兼容已有内容快照，模板中的邮箱和地址段落仍可读取，但不在咨询区重复展示。

解析器遇到旧正文或不符合模板的结构时，完整显示普通正文，不丢弃内容。更改区块顺序、增加介绍段落等操作可能触发普通正文布局；大幅调整内容结构时，应同步调整解析器和测试。

荣誉卡片保留「年份三级标题 + 名称段落 + 说明段落」，后续可增加说明段落和图片（含图注）。旧版两段文字卡片继续适用；陌生结构完整回退到普通正文。业务边界仍为引用块，原文中的业务限制和 ESG 合作伙伴定位加粗。

## 现有 CMS 定向更新

在已配置目标数据库与媒体目录的环境运行：

```sh
npm run update:experience-content -w @empact/cms -- --dry-run
npm run update:experience-content -w @empact/cms -- --apply
```

默认只预检。`--apply` 先把两页原始记录备份到 `.data/backups/experience-<时间>/pages.json`，再导入缺失图片并在事务中更新关于页四个指定奖项、业务边界、三处亚太地点数量，以及隐私页咨询字段与用途说明。地点数量按对应文案定位，仅将历史口径 13 改为 12，其他数字不变；遇到其他数量则停止核对。保留其他正文节点和额外荣誉；目标区块缺失、重复或在执行期间被修改时停止。保存后读取核对，再提交事务。重复执行不重复导入图片，也不重复改写相同正文。

更新过的正文及新图片处于未审核状态；命令不执行 CMS 发布。完成审核后，须将关于页、隐私页按现有发布流程发布，并核对线上图片与正文。代码上线和 CMS 内容发布分别验收。
