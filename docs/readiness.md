# 交付验收状态

依据 2026-09-09 的 v1.1 计划与精简首发范围实施。工程、私有后台和部署资料已准备；正式内容及目标服务器尚未放行，不能将本机验证写成 empact.cn 已部署。

## 已实现

- 首页、青少年项目/企业服务总览、动态业务详情、项目、新闻、关于、联系、隐私、条款和真实 404；只将已发布业务加入正式导航。
- 案例与外部报道嵌入所属页面，跨业务关联链接；ChatCircle 独立平台入口，不接触其数据或账号。
- 单管理员图形后台、富文本、图片授权字段、内容与素材审批、独立 SQLite、生产数据库迁移、本机账号初始化/恢复。
- 登录保护的草稿与一小时预览；选定内容冻结发布、原子切换、构建失败保留旧站、指定版本回滚、旧任务重试保护、下线关联校验及截止状态刷新。
- 可读取 HTML、规范 URL、页面元数据、结构化数据、站点地图及机器人边界；桌面/移动导航、键盘操作和咨询状态反馈。
- 同域 SMTP 咨询、输入校验、限流、幂等、蜜罐、来源校验、无配置时关闭收件；不伪造投递成功。
- 独立 systemd 服务、现有 Caddy 合并片段、备份/恢复脚本、CI 和运维说明。

## 验证证据与范围

`npm run verify` 包含类型检查、自动化测试、正式模板的合成审批数据构建检查、CMS 生产构建、临时数据库的真实 HTTP 编辑发布流程、桌面和移动浏览器测试。合成内容只存在于临时验收环境，不能作为公司正式素材使用。

`tests/cms-live.ts` 从空 SQLite 迁移开始，验证登录、草稿/媒体访问边界、真实 PNG 上传、富文本转换、受保护预览、发布、修改草稿不影响线上、项目自动关联、路径冻结、图片引用保护、下线和指定版本恢复。`tests/publisher.test.ts` 注入构建与切换后核验故障，验证旧站保留、首次失败不留公开指针以及并发互斥。

咨询测试使用可控传输器验证接收/拒收分支；没有真实 SMTP 邮箱，因此不构成公网实际收件证明。部署脚本已做 shell 语法检查，尚未在 Linux/systemd 和目标 ECS 执行恢复演练。

依赖审查：生产依赖无 high/critical 告警；Payload 的一项 moderate 根告警传播到 7 个依赖节点，已用显式管理员 unlock 权限约束，详细解释见 [依赖审查](dependency-review.md)。未通过强制降级隐藏告警。
