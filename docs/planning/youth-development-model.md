# 国际化人才培养模型：实现计划与内容说明

## 范围

- 青少年总览在项目列表前展示培养理念与模型入口。
- 在青少年导航下提供 `/youth/development-model/`，纳入正式站点 sitemap。
- 模型使用 SVG 几何与可读网页文字：主体性、五项内在特质、原名六维能力。
- 手机端改为纵向阅读；子页补充根与远方、五步成长过程和返回项目入口。

## 视觉与内容

沿用官网蓝色、青绿、珊瑚色，紫色辅助区分节点。外圈六边形对应六维能力，内圈五边形的五个顶点对应五项内在特质；无背景填充、纯色细线、统一中文排版；不依赖外部字体、图片服务或动画。保留开物 KAIWU 模型来源，正文为面向青少年的解释，不宣称原创或已验证的培养成效。Empact offsite 网页仅参考外围六节点布局，不采用其改写的第五、六维名称。

这部分为开发维护的固定方法论页面，不新增 CMS 模型、活动记录或发布权限；已有项目内容仍由快照管理。后续如需运营人员编辑模型各维度，应另行定义结构化字段。

## 验收

Astro 检查、预览构建、输出链接及元数据检查；浏览器检查入口往返、六维可见、成长步骤、手机到桌面宽度无横向溢出，人工查看简图排版。仅交付 PR 和本地预览，不部署生产。
