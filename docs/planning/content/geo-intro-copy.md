## CMS 更新方式与回执

批量更新使用幂等工具（默认 dry-run）：

```bash
npm run update:geo-intro-content -w @empact/cms            # 预检，输出逐条状态
npm run update:geo-intro-content -w @empact/cms -- --apply # 事务内更新草稿
```

- 按 kind + slug 唯一定位，逐条核对正文首段与本次盘点记录的预期旧文案；已被他人编辑的条目报冲突并跳过，不强行覆盖。
- 只替换正文首段（页面要求正文仅一段），保留其他 Lexical 节点、媒体、关系与发布状态；重复执行不重复插入。
- apply 前把目标条目旧值与回执写入 `.data/backups/geo-intro-<时间戳>/`（受保护运行目录，不入库）。
- 更新后条目回到 `approved=false` 草稿状态，须经既有审核、发布链路才会影响公开页面；工具不发布、不连带其他草稿。
- 2026-09-26 已对本地库副本完成验证：dry-run 21 条目标全部可更新、无冲突；apply 后 21 条更新，再次执行全部幂等（current）。
