# 首页 Logo 汇聚与照片带

## 本轮范围

- 首屏使用现有真实 Empact 标识：散点汇聚、恢复完整品牌色，再向上移动并缩小，为照片带留出位置。
- 同一图片列表支持纯照片与胶卷两种表现，横向连续滑动，两端渐隐；本地预览提供样式切换。
- 新增独立的「首页照片」后台，维护图片、描述、顺序和默认样式，接入既有预览及发布流程。
- 用户稍后提供正式照片。当前仅在预览模式展示明确的占位图；正式站没有配置时不显示占位内容。

## 视觉与节奏

- 延续品牌蓝 `#125284`、米白 `#F3F0E7`、白色 `#FFFFFF`，原标识保留红 `#FB394D` 及彩色花瓣，不另造标识。
- 字体沿用首页 Arial / PingFang SC；Logo 是主要识别元素，标语与操作保持克制。
- 约前 2.2 秒汇聚为点阵，约 3.2 秒填实；随后约 1 秒上移缩小，照片带渐入。
- 纯照片版以整齐照片画幅为主；胶卷版以深色胶片和上下齿孔区分。两版数据、速度、暂停行为一致。

## 交互与降级

- 导航和滚动始终可用。提前滚动会结束开场并衔接原有滚动，返回顶部不重复汇聚。
- 持续滑动提供暂停，悬停/键盘聚焦、离屏及页面隐藏时停止。减少动态效果时展示静态可浏览照片。
- 关闭 JavaScript、Canvas/图片加载失败、短横屏和放大文字时保留静态 Logo、照片及原有业务入口。
- 兼容缺少 homeGallery 的旧快照；图库保存、预览、发布各自遵循既有内容流程。

## 验证与交付

1. 核对开场聚合、填实、上移缩小和照片淡入的先后关系。
2. 验证纯照片/胶卷切换、无缝循环、暂停、触摸浏览、边缘渐隐、单图与空配置。
3. 验证后台图片保存/排序、预览、发布快照与媒体引用、数据库迁移。
4. 验证桌面/手机、提前下滑/返回、减少动态效果和现有四屏滚动回归。
5. 在唯一工作区的 4321 开发预览提供两版，完成检查后提交 ready PR；本轮不合并或部署。

## 后台使用与迁移

- 后台工作台的「首页照片」独立入口打开 `/admin/globals/home-gallery`。选择纯照片或胶卷、添加图片、拖动排序、填写可选描述，保存后生成预览，再发布预览版本。
- 图库发布只更新首页照片与所选样式，保留其他已发布内容。照片被草稿或已发布版本引用时不能删除。
- 新迁移 `20260923_044956_home_gallery` 只新增图库配置与照片排序两张表，不改写已有业务表。旧快照缺少图库字段时仍能读取。
- 本地已备份数据库并在副本验证迁移，应用后校验原有 17 张业务表内容未变、数据库完整性正常；备份与读回结果位于忽略目录 `.data/home-gallery-20260923/`。
- 正式环境存在真实结构变更，自动部署保护会拦截；上线前须按 `docs/automatic-deployment.md` 独立评估并执行迁移。本轮不调整该保护或发布正式内容。
