# 文字驱动前端改版验收

2026-09-10，依据[前端重构计划](前端重构计划.md)及同目录三个已选样张。

## 实现

- 首页采用品牌蓝、三行英文标题、红色星形与绿色箭头；双业务矩阵直接遍历当前内容，不固定业务数量。
- 导航、业务详情、案例、ChatCircle、关于及政策页沿用统一字阶、分隔线与阅读面。Logo 使用原图原色，无外部字体或新增网络依赖。
- 咨询页采用蓝色介绍栏与浅色真实表单；字段、同意项、发送逻辑、开放条件与状态文案沿用现有逻辑。
- 手机导航提供展开、关闭、Escape 和返回焦点；无脚本仍可访问主要入口。导航根据可用宽度在 56em 切换，内容最大宽度 80rem，长文 40rem。
- 内容默认可见；进入视区时渐显一次，聚焦时取消过渡；减少动态效果设置会禁用动画，星形离屏暂停。
- ChatCircle 导航仅在当前可用内容包含该项目时显示，避免生产模式下链接到未发布项目。

## 验证

- `npm run check`：通过。
- `npm test`：16 项通过，包括生产静态输出、内容审核与咨询边界。
- `PREVIEW_PORT=4332 npm run test:browser`：桌面与手机 10 项通过；覆盖 320、768、820、1024、1920px，菜单焦点与关闭、无脚本、减少动态效果、图片、案例锚点及咨询未开放状态。
- `SITE_MODE=preview npm run check:output`：HTML、元数据、链接、CSP、索引检查通过。
- 已人工核对桌面和手机首页、业务矩阵、案例与咨询页截图；截图由浏览器测试输出到 `test-results/`，不纳入发布内容。
