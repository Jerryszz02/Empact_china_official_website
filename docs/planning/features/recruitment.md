# 加入我们与招聘管理

官网入口位于顶部导航的「关于 Empact」右侧。页面地址为 `/join-us/`，岗位按钮跳转到 `/join-us/apply/?job=<岗位ID>`，申请表会自动选中该岗位。

## 编辑与发布岗位

1. 后台打开「招聘管理」。首次进入时提供三个示例岗位，可以直接修改或删除，也可以新增岗位、拖动调整顺序。
2. 填写岗位名称、类型、地点、简介、工作职责、任职要求和到岗安排。职责与要求每行一条；岗位 ID 是英文小写、数字和连字符组成的唯一标识，发布后尽量保持稳定。
3. 确认真实招聘信息后取消「示例岗位」标记。示例只在预览中出现，不展示到正式站点，也不接收申请。
4. 保存后点击「生成预览」，打开招聘预览检查内容，再点击「发布预览版本」。发布的是刚才生成的预览；再次修改后需要重新保存和预览。
5. 招聘结束时将状态改为「已关闭」或删除岗位，再预览、发布。正式页面与申请下拉框会同步移除该岗位，已打开旧表单的申请也会被服务端拒绝。

招聘可以单独发布，不会带上其他栏目尚未发布的草稿。暂时没有真实开放岗位时，官网显示「目前暂无开放岗位」。

## 编辑与发布办公空间照片

后台打开「办公空间照片」（`/admin/globals/office-gallery`），新增照片行，选择或上传图片，并填写必填的「图片说明」（caption，最多 200 字）。照片可拖动排序、替换或删除。

保存后点击「生成预览」，打开「加入我们」预览确认照片与说明，再点击「发布预览版本」。办公空间照片可单独发布，不会带上首页照片、招聘岗位或其他未发布草稿；仅保存不会改变官网。

尚未配置时保留下方两张默认照片。首次发布自定义列表后替换默认照片；删除全部照片并发布会隐藏「一起工作的地方」区块。一张或两张照片静态展示，多张超出区域时可触摸左右滑动、使用左右按钮或聚焦照片区域后使用方向键，不自动轮播。

## 申请表与邮件

申请表收集岗位、姓名、邮箱、可选的电话或微信、相关经历、到岗时间，以及至少一个简历或作品链接。链接须使用 HTTP 或 HTTPS，并对招聘负责人开放访问；当前不上传简历附件。

招聘复用咨询表单的 `/api/contact`、SMTP 配置和 `CONTACT_TO` 收件箱。主题为「Empact 官网招聘申请：岗位名称」，正文包含申请资料和申请人邮箱。公开联系方式 `company.email` 不决定实际收件箱。

真实邮件发送沿用现有咨询开关和公司、隐私资料确认状态。页面预览始终禁用发送；自动化检查使用隔离数据或模拟邮件投递，不会发送真实申请。

## 数据库变更

办公空间照片另增 Payload `office-gallery` Global，对应 `office_gallery` 与 `office_gallery_photos` 两张表及三个索引；可选快照字段 `officeGallery` 兼容旧版本。

新增 Payload `recruitment` Global 与 `recruitment_jobs` 子表，旧内容快照仍可读取。迁移及对应的部署结构计划仅新增这两张表和两个索引，按 `docs/planning/operations/automatic-deployment.md` 走现有增量迁移流程。
