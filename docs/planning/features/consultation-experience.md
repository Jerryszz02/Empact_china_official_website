# 咨询与页面体验调整

首页依次为品牌、我们是谁、四大业务、咨询与合作四屏，背景为深蓝、浅色、浅色、深蓝。桌面滚轮分页使用实际场景锚点；移动端、减少动画和内容超高时保留自然滚动，页脚始终可达。

## 咨询字段与兼容

业务范围包括青少年、企业、学校、社区与其他／暂不确定。子业务来自当前内容快照，切换范围时清空选择；原有 `?business=<业务 ID>`、大类值与 `other` 链接继续可用。

必填为咨询方向、称呼、一种联系方式、需求说明和隐私同意。机构、职位、目标、地点、时间、人数、预算、资料链接选填；不提供附件上传。接口仍为 `POST /api/contact`，沿用原有邮件配置与开放条件。

新请求通过 `segment` 标识新表单，服务端要求称呼与子业务。旧请求未提供 `segment` 时仍接受原有字段。服务端限制长度、拒绝非法资料链接，将中文业务路径与全部填写详情写入邮件；所有实际投递字段均参与幂等摘要。失败保留输入与提交标识，成功后禁用再次提交。

## 内容与发布

关于页奖项和隐私声明的模板、定向草稿更新及照片依据见[关于页说明](about-page.md)。代码部署不替代 CMS 正文发布，内容更新命令不修改公开快照。

案例文章顶部和文末链接返回实际父业务，缺少父业务时返回对应大类。后台全局顶部链接在新标签打开本站首页，保留当前编辑页面。

## 验证范围

- `tests/contact.test.ts`：新旧请求、邮件正文、隐私同意、幂等、失败重试。
- `tests/public-server.test.ts`：完整中文详情的请求体边界与上线开放条件。
- `tests/experience-content-update.test.ts`：定向修改、其他节点保留、重复执行及图片序列化。
- `tests/browser/contact.spec.ts`：两级联动、旧链接、必填、失败保留、成功禁用及案例返回。
- `tests/browser/motion.spec.ts`：四屏往返、页脚、移动端、减少动画及降级。
- `tests/browser/about.spec.ts` 与 `tests/about-parser.test.ts`：图片加载、新旧结构及未知结构回退。
- `tests/cms-live.ts`：CMS 种子媒体保存及后台首页入口的浏览器点击。

隔离测试使用模拟邮件投递；它不能证明正式邮件已送达收件箱。正式 CMS 发布和代码上线后，须分别核对公开正文、图片与代码版本。
