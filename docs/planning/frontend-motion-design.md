## Overview

使用场景为用户原话：「手机上，经常单手；电脑前，或投在大屏上」。

已确认选择：「取其神（浅色 / 连接感），但是主题颜色还是要empact的蓝色 可以用米白、红、绿点缀，参考我发给你的这张品牌颜色图」。

最新配色修订：首屏以 Empact 蓝作基底、米白作文字；滚至业务屏切为米白底蓝字；底部咨询屏回到蓝底米白字。米白留白集中在中段。真实 Logo 形成粒子，随原生滚动散开、连接两条业务路径，再重组。以动效串起稀疏内容：品牌首屏、业务入口、咨询引导。不要用动效重新塞回已减掉的信息。

本文件是列宾方向确认交付，连同 `motion-demo.html` 交给后续实现；并非生产首页已经完成。本次胜出样张已随文档归档；品牌图保存在 `motion-brand-reference.png`。本次只改配色及保存已确认方向，没有再组织三选一。

## Colors

Empact 蓝用于标题、正文、导航、主按钮及大部分粒子。首尾以蓝色为大面积底色，中段以米白为底色。导航、粒子主色、按钮随场景反转，以保留辨识度。红色、青绿色用于少量粒子与强调点，不能与蓝色争夺主导。

品牌颜色采用图中印出的 HEX 和相符的 RGB，不能对色块截图采样后覆盖标准值。图中蓝色明文为 RGB 18, 82, 132；红色为 RGB 251, 57, 77；青绿为 RGB 44, 179, 185（均为用户提供的明确数值，本次选择采用，来源类别记为「我们定的」，不是推测色值）。

米白为本次设计补充；图中其余粉色、紫色保留在品牌资产中，本次首页不启用。彩色粒子数量采用蓝色 80%、红色 10%、青绿 10%（我们定的，属于可调整的装饰配比，不是品牌规范）。

正文和重要操作用蓝色／米白、白色／蓝色组合。红、青绿只作装饰，不单独以颜色传达业务、错误或成功状态。

## Typography

以系统可用字体展示真实中文，使用常规字重。标题靠尺度与留白形成层级。正文行高见 YAML；中西文混排留 0.25em（我们定的），中文标点使用字体可用的挤压能力，不依赖不存在的字重档。

桌面标题在 2.8em 至 6em 之间随视口变化；手机标题参考 2.9em（我们定的，来自胜出样张，不是品牌原规范）。中文标题保持零字距。投屏时把中文品牌主张和两条业务入口作为阅读主体，英文小标签仅为辅助。

真实文案固定使用「赋能更大的影响力」「从你的关注出发」「青少年项目」「企业服务」「从一次交流开始」「咨询与合作」。服务详情留在相应内页；具体文案扩充需回到内容审阅流程。

## Layout

全页共用连续舞台，每屏表达一个主要信息。桌面首屏采用右上粒子 Logo、左下中文主张；业务屏保留两个明确入口；结束屏以 Logo 重组和咨询引导收束。

桌面左右留白占视口宽度 0.06；手机左右留白使用 YAML token。桌面 Logo 起始中心约在横向 0.66、纵向 0.33；手机约在横向 0.5、纵向 0.31（均为我们定的，记录胜出样张比例，不是品牌固定网格）。手机优先上下排列，保证文字与粒子主轮廓互不遮挡。

每个场景占一个可见视口，内容过高时允许自然增长。样张的滚动总长为视口高度的 3 倍（我们定的，供体验节奏使用，不是生产硬编码要求）。正式实现以实际内容和浏览器动态工具栏调整，按用户最新反馈，三个完整场景使用原生 CSS 强制滚动吸附，松手后停在完整的一屏；不接管滚轮或触摸事件。

## Elevation & Depth

通过留白、粒子位置和少量运动制造纵深；页面内容不依赖浮起卡片或厚重阴影。操作保持前景清晰，装饰粒子位于文本之后。样张控制按钮是试玩工具，不属于官网组件。

## Shapes

保留真实 Empact Logo 的字形、下划线与花形标识。粒子是 Logo 的演绎，不用近似字体拼出替代标识。胶囊只用于可点击操作；业务入口保持开放的排版和轻线条。

## Components

### 品牌粒子与滚动

粒子从真实 Logo 像素采样生成。停留首屏时保持轮廓可识别；下滑后散开并连接业务区域；到结束屏再汇聚为 Logo。向上滚动应可逆。配色遵循 Colors。

样张归一化进度约在 0.1 后开始打散、0.75 后进入重组、0.95 前恢复轮廓（我们定的，保留实验参数，正式实现可围绕内容位置调整）。业务屏显示时粒子避开文本焦点，不让粒子数量压过“连接”的含义。

系统要求减少动态效果时，改为静态品牌视觉和自然内容呈现；保留所有业务入口。正式产品关闭 JavaScript 后仍能读取正文、进入业务和咨询，不能把样张中依赖 JS 切换的隐藏场景直接迁入产品。无需 hover 才能理解内容，键盘和单手触屏均可操作。

### 业务入口与咨询

青少年项目、企业服务始终是两个独立入口。正式实现分别进入现有业务页；样张中的入口只推进到咨询场景，不代表最终链接行为。底部咨询入口使用米白底蓝字，与蓝底场景形成对比。

单手触控区域最低以正文基准的 2.75em 设计（我们定的）；实际实现检查根字号换算后尺寸，不能因为缩小英文标签字号而缩小可点击范围。大屏保持品牌主张和主操作可见，不能用小屏截图整体放大充当响应式布局。

### 验收边界

以 `motion-demo.html` 的蓝—米白—蓝背景节奏、蓝色主导、彩色点缀及粒子重组为确认依据。正式实现后按列宾验收流程检查样张与成品气质、横向溢出、控制台错误、图像比例、图片体积、文本对比度及关闭 JS 的正文可用性。样张检查通过不等于正式上线验收。

## Do's and Don'ts

### 用户确认原话

「取其神（浅色 / 连接感），但是主题颜色还是要empact的蓝色 可以用米白、红、绿点缀，参考我发给你的这张品牌颜色图」

### 后续滚动与导航修订

用户要求：「我希望滑动的时候在这三个页面都有停顿感 就是不要花一下卡在中间一半的地方了」。样张增加三个场景吸附点，保留过渡动画，停止滚动时对齐完整场景。

用户要求 ChatCircle 出现在导航栏，首页不必增加区块。沿用当前预览代码中 ChatCircle 的地址 `https://chatcircle.empact.cn`，手机与桌面均可见。

### 后续配色修订原话

「修改一下吧 把米白和蓝色换一下？然后滑下去再是现在这个样子 再滑到底就还是蓝色作为基底 你按照这个修改一下demo」

保留「取其神」的构图和粒子动效，按这条最新反馈覆盖此前全页浅色底的表述。

### 用户否决原话

「第一个黑色的不符合我们的腔调 第三个不符合我想要的动效效果」

对应关系：第一个为「贴着做」，第三个为「反着来」。上面完整原话不做润色或拆写。

### 什么时候别用这套

这套全屏动效适用于品牌首页。CMS 后台、长服务列表、表单填写、隐私条款和以查找为目的的页面使用普通内容布局。遇到较弱设备、减少动态效果偏好或内容超出一屏时，先确保阅读和操作，再降低装饰密度。

## 实现时的创意指令

在尊重本文件已确认的设计方向、真实内容和用户原话约束的前提下，充分发挥你的设计创造力。

开始实现前，用工具生成一串随机字母与数字，从其中的组合、节奏和联想中寻找灵感，用于尚未确定的构图、排版、色彩、图像和交互设计。随机字符串仅供创作启发，不要出现在页面中。

大胆做出具体、有个性的设计选择，尝试你通常不会首先采用的表达。需要时使用图片生成来实现关键视觉。运用你的判断，让这些选择形成一个完整、有吸引力、适合这个产品的设计。
