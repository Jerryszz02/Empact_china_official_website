# Empact 中国官网前端优化计划

状态：**计划中；设计方向已确认，正式首页尚未按本计划实现。**

更新时间：2026-09-10。来源：本轮列宾 Demo 及用户最终认可；代码基线为本次更新后的 `origin/main`（`0c78808`）。本次仅归档计划、样张与规范，不修改产品代码，不代表上线。

## 目标与范围

首页从信息密集的文字与业务矩阵，调整为三屏连续品牌体验：降低同屏信息密度，用真实 Logo 的粒子打散与重组串联业务入口；滚动结束后停在完整场景。兼顾「手机上，经常单手；电脑前，或投在大屏上」。

本轮包括首页布局、品牌颜色、Logo 动效、三屏吸附及全站导航适配。保留青少年、企业、关于 Empact、ChatCircle、咨询与合作的访问路径；既有业务详情、案例、新闻及内容不得因首页精简被删除或失去访问路径。

不在本轮重做 CMS、发布器、咨询服务端、内容 schema 或 ChatCircle 应用。现有内页以保证导航和色彩兼容为限，不扩展为全站全屏动效。内容审批、正式发布继续走既有流程。

## 已确认的体验

| 场景 | 内容与入口 | 配色 | 动效与停留 |
| --- | --- | --- | --- |
| 首屏：品牌 | 「赋能更大的影响力」及 Empact 品牌文案 | Empact 蓝底、米白字 | 真实 Logo 形成粒子轮廓；进入时可直接阅读 |
| 中屏：业务 | 「从你的关注出发」、青少年项目、企业服务 | 米白底、Empact 蓝字 | Logo 粒子打散铺开，保持两类入口清晰；停留时内容完整 |
| 尾屏：交流 | 「从一次交流开始」、咨询与合作 | 回到 Empact 蓝底、米白字；米白按钮蓝字 | 粒子重新组成 Logo，落到稳定的咨询引导场景 |

- 导航包含 ChatCircle；首页不新增 ChatCircle 独立展示屏。保留关于 Empact 等现有必要入口，不能照抄 Demo 中简化的导航而丢失功能。
- ChatCircle 沿用代码中已有的 `https://chatcircle.empact.cn` 地址和内容可用性判断，不新增嵌入页面或改造其域名。未发布内容的可见性边界不因演示导航而绕过。
- 正式业务按钮分别进入现有青少年、企业页面；Demo 中推进咨询场景的按钮仅是演示交互，不可原样迁入。
- 以 [可滚动 Demo](motion-demo.html) 为已确认视觉基准；以 [设计规范](frontend-motion-design.md) 为色彩、排版及用户原话基准。HTML 可离线打开，外部业务链接需网络，本地咨询链接只用于本机演示。

## 技术实施方案

### 页面结构与内容

在 `apps/site/src/pages/index.astro` 整理三个语义场景，继续从现有内容快照获取可发布内容。标题、链接、说明保留在服务端生成的 HTML 中；Canvas 仅承担装饰。不能将 Demo 的绝对定位、透明隐藏全部复制到默认正文上。

先盘点现有首页业务、案例、新闻和项目链接，再记录精简后的去向：业务与其案例留在所属业务页面；新闻和其他已发布项目保留可发现的入口。若已有内容缺少可访问入口，实施时补齐最小入口或提出具体内容归属问题，不静默删掉。

复用 `Header.astro`、`Footer.astro` 和既有内容路由，首页动效样式限定作用域；`global.css` 只调整共享品牌 token、导航必要样式。内页的正常纵向阅读不应用首页吸附。

### 粒子与生命周期

优先采用原生 Canvas 2D 和现有 Astro 客户端脚本，不引入新的动画框架、字体服务或外部请求。Logo 使用仓库合法品牌资产，按实际尺寸采样，保留原比例。

滚动进度驱动轮廓散开、场景切换和重组，反向滚动可逆。使用 `requestAnimationFrame` 合并渲染；停止滚动且无动态输入时停止刷新，页面不可见时暂停；尺寸变化重新计算画布及比例。手机降低粒子数量、限制设备像素比，避免把高分屏当作无限绘制预算。粒子密度和时间曲线以真实设备评估，不把 Demo 采样数量视为硬性指标。

### 三屏吸附与可访问性

优先使用原生 `scroll-snap-type`、`scroll-snap-align`、`scroll-snap-stop` 形成三个停靠点；保留普通滚轮、触控、键盘操作，不添加阻止默认事件的整页滚动劫持。滑动松手后停在首、中、尾完整状态，不能留在一半换色或几乎无正文的进度。

短距离滑动可以回到当前屏；完成翻屏手势后进入相邻屏。重滑需实测不会不受控越过中屏。菜单展开、焦点移动、直接导航至业务或咨询时，不被吸附拉回其他场景；移出首页动效范围后可访问页脚。

高度以实际可见区域计算，处理移动浏览器工具栏、横竖屏与缩放。内容因窄屏、放大字体而超过视口时，允许自然增长并降低／关闭强制吸附，保证每段文字、链接及页脚都可到达。

减少动态效果偏好下使用静态 Logo 和稳定色块，弱化或关闭全屏过渡与强制吸附。无 JavaScript、Canvas 不可用或 Logo 加载失败时，正文和导航仍可用，显示静态品牌替代图。隐藏场景不能持有键盘焦点，Canvas 不进入可访问树。

### 导航与真实链接

在 `apps/site/src/components/Header.astro` 延用手机菜单的展开、关闭、Escape、焦点返回及无脚本行为。手机可根据空间使用现有菜单；Demo 的两行导航是视觉参考，所有真实入口均须能访问。ChatCircle 不依赖 hover 才能发现。

`apps/site/src/lib/content.ts` 已存在 ChatCircle 外链映射，本轮不重复创建或改写为本地占位路由。链接是否另开窗口保持现有约定；若另开窗口，补足安全属性及可访问提示。

## 分步执行与完成条件

1. **内容与页面结构**：完成首页内容去向清单，落实三个语义场景和真实链接。无脚本仍可阅读、导航。
2. **品牌与导航**：应用标准配色、背景切换及 ChatCircle 入口；验证内页导航和手机菜单不回归。
3. **粒子与吸附**：接入粒子、三屏停靠和反向滚动；补齐弱设备、减少动态效果及内容超高降级。
4. **验收与交付**：运行相关检查，保存首中尾、手机与大屏截图，核对 Demo；更新实现状态、提交限定差异并创建 ready PR。发布另按既有流程执行。

每步只在实现及相应检查有证据时改成已验证。主负责人维护需求、关键决策与最终验收，避免把样张检查等同于生产实现检查。

## 验收清单

| 项目 | 通过条件 |
| --- | --- |
| 三段配色 | 首尾精确为品牌蓝，中屏米白；正文和操作始终可读 |
| 吸附 | 鼠标滚轮、触控板、手机触摸停止后落在完整场景；上滑可逆；不困住焦点或页脚 |
| 连续性 | Logo 可识别，散开与重组连续；无闪白、残影或停在半透明文字的状态 |
| 导航 | 手机、桌面可访问青少年、企业、关于、ChatCircle、咨询；外链地址正确 |
| 内容 | 三屏精简不造成原有已发布内容丢失或链接失效；不引入样张假按钮 |
| 响应式 | 至少检查 390、1440、1920 宽度，并覆盖窄屏、横屏、放大字体；无横向溢出或 Logo 拉伸 |
| 无障碍 | 键盘焦点与菜单关闭正常；减少动态效果、无 JS、Canvas 失败仍能完成导航和咨询入口访问 |
| 性能 | 真实手机滚动不卡顿；空闲及后台不持续绘制；记录实际设备与测量条件，未测不报性能达标 |
| 回归 | 现有审核、内容路由、咨询状态、SEO 和构建检查保持通过 |
