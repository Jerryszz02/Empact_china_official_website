# 素材目录

`assets/` 存放原始图片、业务资料、工作簿及其来源索引。它与 `artifacts/` 的用途不同：后者保存验收截图、浏览器日志、临时脚本和处理结果，默认不进入 Git。

| 位置 | 用途 |
| --- | --- |
| `原始照片/2026-09-23/` | 原工作区根目录的 15 张照片，保留文件名和原始字节；本机归档，不随公开仓库提交。日期为收到文件的日期，不代表拍摄日期 |
| `品牌与设计/` | 长期保留的品牌颜色等设计参考 |
| `01-青少年业务/` 至 `04-社区业务/` | 按业务分类的原始材料；可包含仅在本机保存的大型或内部文件 |
| `业务源资料/` | 公司介绍、课程与项目资料；[业务目录工作簿](业务源资料/Empact网站业务目录.xlsx)为来源材料，不自动等同于最新版 CMS |
| `cases-images/` | 既有活动图片档案、来源清单和归档工具 |
| `日历计划表-2026/` | 活动日历原表、解析结果和配套整理工具 |

新增图片优先放入对应业务目录，尚未确认业务归属的放入 `原始照片/<收集日期>/`。保留原文件；压缩或转换另存网站副本。收集日期、文件名及文件夹名称不能单独证明活动时间、项目归属或公开授权。

网站直接使用的文件有各自的位置：`apps/site/src/assets/` 是 Astro 引用的图片，`apps/site/public/brand/` 是固定品牌文件，`packages/content/fixtures/media/` 是预览及首次导入媒体。CMS 上传原图和数据库位于私有 `.data/` 或服务器数据目录。移动本目录素材不会自动更新网站，也不能把这些运行数据当临时文件删除。

素材下载与发布流程见[内容维护清单](../docs/planning/content/content-checklist.md)和[案例上传说明](../docs/planning/content/case-upload-guide.md)。现有素材工具按文件所在位置读写关联资料，整理目录时需一起核对；不要为整理而重新运行下载、导入或发布命令。
